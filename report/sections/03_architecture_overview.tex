\subsection{Architectural Decoupling and Module Hierarchy}

The codebase is organized into four core functional layers:

\begin{enumerate}
    \item \textbf{Orchestration Layer} (\texttt{run.py}, \texttt{pipeline.py}): Handles dataset loading, CLI argument parsing, runtime batching, stream output serialisation, and instantiates the selected variant execution model.
    \item \textbf{Agentic Reasoning Layer} (\texttt{agents/}): Encapsulates domain classification, specialized diagnostic analysis, cross-domain report synthesis, and consensus verification logic into discrete agent classes inheriting from \texttt{BaseAgent}.
    \item \textbf{Knowledge Retrieval Layer} (\texttt{agents/rag\_agent.py}, \texttt{corpus/}): Encapsulates the MedCPT dense vector search engine and preprocessed medical textbook chunk indices.
    \item \textbf{State Management Layer} (\texttt{memory.py}): Coordinates transient intra-vignette scratchpad storage (\texttt{ShortTermMemory}) and persistent disk cache storage (\texttt{LongTermMemory}).
\end{enumerate}

\subsection{Architectural Invariants and Design Guarantees}

The system enforces three strict design guarantees:

\begin{itemize}
    \item \textbf{Stateless Agent Invariant}: Agents do not retain internal mutable state across invocations. All operational context must be explicitly passed via parameters or retrieved from the \texttt{ShortTermMemory} bus.
    \item \textbf{Context Boundary Invariant}: Short-term memory is forcibly purged prior to processing a new clinical vignette, preventing context bleeding between separate test cases.
    \item \textbf{Deterministic Formatting Guarantee}: All agent outputs undergo structural validation and regex extraction. Unparseable responses trigger strict retry loops, guaranteeing an invalid response rate of $0.0\%$.
\end{itemize}
