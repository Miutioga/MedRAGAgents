  {\huge\bfseries MedRAGAgents: Architecture, Implementation, and Evaluation of a Multi-Specialty Agentic Retrieval-Augmented System for Medical Reasoning\par}
  
  \vspace{1.5cm}
  {\Large\bfseries Project Technical Report \& System Specification\par}
  
  \vspace{2.0cm}
  \textbf{Author:} Senior AI Systems Architect \& Clinical NLP Engineer\\
  \textbf{Institution:} Department of Computer Science \& Software Engineering\\
  \textbf{Target Domain:} Machine Learning in Security \& Biomedical Reasoning (UIT-SDH)\\
  \textbf{Benchmark Target:} MedQA-USMLE Medical Board Examination Dataset\\
  \textbf{Compiler Target:} XeLaTeX Standard Engine\\
  \textbf{Date:} August 2026
  
  \vfill
  
  \begin{abstract}
  \noindent Standard single-prompt foundation model architectures encounter severe cognitive bottlenecks, knowledge cutoff limitations, and domain hallucination when evaluating complex clinical vignettes requiring multi-disciplinary specialty reasoning. This report presents \textbf{MedRAGAgents}, a production-grade multi-agent medical reasoning architecture integrating domain-specialized decomposition, biomedical dense vector retrieval via MedCPT over a preprocessed textbook corpus, and a dual-layer memory infrastructure. MedRAGAgents structures clinical diagnostic inference across five discrete agent roles: Domain Classification (\texttt{DomainAgent}), Parallel Specialty Analysis (\texttt{AnalysisAgent}), Comprehensive Synthesis (\texttt{SynthesisAgent}), and Iterative Consensus Verification (\texttt{VerifierAgent}). To minimize redundant API transaction latencies and guarantee state isolation, the pipeline relies on an intra-turn in-RAM scratchpad (\texttt{ShortTermMemory}) paired with an inter-turn persistent SHA-256 canonical digest key-value cache (\texttt{LongTermMemory}). On the MedQA-USMLE benchmark dataset ($N=1,273$), the unified system architecture (Variant V3) yields substantial accuracy improvements over direct chain-of-thought baselines while maintaining an output formatting invalidity rate of $0.0\%$. We provide formal mathematical task definitions, full architectural specifications, 12 monochrome engineering diagrams, algorithmic listings, statistical power checks via 1,000-resample non-parametric bootstrap confidence intervals, McNemar significance testing, failure mode taxonomies, and operational deployment guidelines.
  \end{abstract}
  
\end{titlepage}
